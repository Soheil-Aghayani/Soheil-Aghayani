## The short version

I am an environmental engineer and sustainability researcher based in Tehran, Iran. My work sits at the intersection of solid waste management, biofuel production, life cycle assessment, data analysis, and software that makes complex work easier to understand.

I like projects with a visible human outcome: a better decision, a clearer workflow, a calmer interface, or a small experiment that makes someone want to keep exploring.

## The research thread

- Solid waste management and waste valorization
- Biofuel production using waste-derived catalysts
- Life cycle assessment with SimaPro and OpenLCA
- Landfill gas modelling and biomass resource assessment
- Circular economy systems that can move from paper to practice

## The build thread

- Python for analysis, automation, and technical tools
- JavaScript and TypeScript for browser experiences
- C# and WPF for desktop software
- Java and JavaFX for native interfaces
- HTML/CSS for fast, expressive prototypes

## Current direction

Building a portfolio that feels like a place rather than a folder: research with evidence, software with a point of view, and small interfaces that reward curiosity.
